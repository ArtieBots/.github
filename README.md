# ArtieBots community health files

GitHub uses the files in this repository as the defaults for every repository in the
ArtieBots organization that doesn't have its own:

- [`SECURITY.md`](./SECURITY.md) - how to report a vulnerability
- [`.github/ISSUE_TEMPLATE/`](./.github/ISSUE_TEMPLATE/) - the bug report and feature request forms
- [`.github/pull_request_template.md`](./.github/pull_request_template.md) - the pull request description template

To override one for a single repository, add a file of the same name to that repository.

The project itself, and its documentation, is at [ArtieBots/Artie](https://github.com/ArtieBots/Artie).
